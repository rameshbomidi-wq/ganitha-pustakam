# 📐 గణిత పుస్తకం – రాయ్ ఎడ్యుకేషన్

1–5 తరగతుల కోసం ఆడుతూ నేర్చుకునే గణిత పుస్తకం (18 అధ్యాయాలు).
వెబ్‌సైట్: https://raayeducation.in

## APK ఎలా వస్తుంది?
1. ఈ ఫోల్డర్‌లోని అన్ని ఫైళ్లను (`.github` ఫోల్డర్‌తో సహా) GitHub repository లో **main** branch కి upload చేయండి.
2. **Actions** ట్యాబ్ → "Build APK" తనంతట మొదలవుతుంది (5–8 నిమిషాలు).
3. పూర్తయ్యాక **Releases** లో `Ganitha-Pustakam.apk` వస్తుంది – ఫోన్‌లో డౌన్‌లోడ్ చేసి install చేయండి.

## వెబ్ యాప్ (GitHub Pages)
Settings → Pages → Branch: main → Save. తర్వాత `https://<username>.github.io/<repo>/` లో తెరుచుకుంటుంది.
